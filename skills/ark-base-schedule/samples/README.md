# 样例说明

本目录用于单元测试、回归测试和输出格式示范。

- `sample_干员练度表.txt` 是合成的功能测试 roster，不代表真实账号。
- `sample_hybrid_solver_*` 用于固定求解链路回归。
- `sample_full_roster_*` 和 `sample_lmd10000_*` 是从实际问题中提取的压缩摘要，保留模型边界和结果字段，不包含原始工作簿。
- 0.7.1 曾生成的超大完整排班 JSON 已从公开仓库移除；发布版本只保留可阅读的摘要和可重新生成的配置。

用户自己的 roster、库存和求解输出应保存在仓库外或被 `.gitignore` 排除。
