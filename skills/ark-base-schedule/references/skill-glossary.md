# 明日方舟基建特殊机制/中间产物/等效效率词典

## 一、中间产物体系

游戏内有几种"中间产物"——看不见的计数器，由某些干员的技能产出，被另一些干员的技能消耗，转化为实际效率。

### 1. 人间烟火

**产出方式：**
| 干员 | 技能 | 产出条件 | 产量 |
|------|------|---------|:----:|
| 夕E2 | 不以物喜（控制中枢） | 心情低于12时 | +15 |
| 令E2 | 山河远阔（控制中枢） | 心情大于12时 | +15 |
| 令E2 | 知我为我（控制中枢） | 每有1名岁干员在非宿舍/活动室设施内 | +5/人 |
| 乌有E2 | "愿者上钩"（贸易站） | 宿舍内每有1名干员 | +1/人 |

**消耗方式：**
| 干员 | 技能 | 转化比 |
|------|------|:------:|
| 乌有E2 | "愿者上钩"（贸易站） | 每1点人间烟火→+1%订单效率 |
| 截云E2 | 古老巫术（制造站） | 5:1转化为巫术结晶，每1点巫术结晶→+1%/2%制造效率 |

## 二、全局计数器体系

这类技能不看同房间的队友，而是**统计全基建范围内满足条件的干员数量**。

### 设计排班时必须追踪的全局计数器

| 计数器 | 影响哪类技能 | 统计范围 |
|--------|-------------|---------|
| **杜林族干员** | 鸿雪（每1名提供1条赤金生产线） | 全基建（除宿舍/活动室） |
| **莱茵生命干员** | 娜斯提（每有1名+3%赤金，最多5名）、缪尔赛思（每有1名+3%无人机） | 全基建（除宿舍/活动室） |
| **精英干员** | 真言（每间有精英干员的设施+2%订单，最多10间） | 全基建（除宿舍/活动室） |
| **岁干员** | 风絮（每间有岁干员的设施+4%订单，最多5间）、令知我为我（每名+5人间烟火） | 全基建（除宿舍/活动室） |
| **格拉斯哥帮** | 摩根（同站每名+20%）、戴菲恩（中枢每名+10%） | 同贸易站 + 全基建 |
| **深海猎人** | 歌蕾蒂娅集群狩猎（深海猎人获特殊加成） | 全基建 |
| **A1/A4小队** | 历阵锐枪芬（每名A1+10%）、现场经验加成 | 同制造站 |
| **叙拉古干员** | 八幡海铃（中枢每名叙拉古+5%订单） | 全贸易站 |

## 三、赤金生产线体系

这是贸易站的一种特殊机制，由多个干员协同组成"生产线"计数器，最终转化为龙门币收益。

### 产业链路

```
杜林族干员进驻设施
    ↓ 鸿雪"际崖居民"每1名提供1条赤金生产线（最多4条）
    ↓
赤金生产线数量
    ├── 鸿雪"销路宣发"：每条生产线→+5%订单效率
    ├── 绮良"订单流可视化·β"：每2条→额外2条
    └── 图耶"物流规划·β"：每2条→额外+15%订单效率
```

### 满配计算（4杜林+鸿雪+图耶+绮良）

| 步骤 | 计算结果 |
|------|---------:|
| 4杜林进驻设施（非宿舍） | 鸿雪生产线=4条 |
| 绮良E2（每2条+2条） | 4条→+4条=8条 |
| 鸿雪"销路宣发"（每条+5%） | 8×5%=**+40%** |
| 图耶E2（每2条+15%） | 8÷2×15%=**+60%** |
| 绮良基础 | +5% |
| 图耶基础 | +5% |
| **等效贸易效率合计** | **40%+60%+5%+5%=110%** |

**等效赤金消耗效率：** 因为鸿雪产线本质是**加速赤金消耗**（不增加龙门币单价），所以会额外消耗赤金。每1条赤金生产线=赤金消耗速度+X%。**这条产线要配合足够的赤金制造才能运转。** 满分全链下赤金消耗可加快35%左右。

## 五、菲亚梅塔充电体系

菲亚梅塔（信仰搅拌机）的基建技能不在"基建技能一览"页面的标准设施分类中，需要单独确认。

### 技能效果
信仰搅拌机的技能是会客室相关（线索搜集），但排班中提到的"菲亚梅塔回复"是指：**放在宿舍的菲亚梅塔可以给特定心情消耗大的干员加速心情回复**，属于宿舍技能范畴。

通常用法：让菲亚梅塔进驻宿舍，给但书、清流等高心情消耗干员提供额外心情回复，从而延长他们连续工作的时间。

## 六、冬时"归零"体系的正确用法

冬时E1的"流程优化"技能：
> 进驻制造站时，当前制造站内其他干员提供的生产力全部归零，每个当前制造站内干员为当前制造站+10%生产力

和温蒂/森蚺的自动化不同，**冬时是按"当前制造站内干员数量"计算**（满员3人×10%=30%），不是按发电站数量。

**冬时 + 清流 + 温蒂 的叠加规则：**
- 清流"每个贸易站为赤金+20%"——属于"根据设施数量提供加成"，**不被冬时归零**
- 温蒂"每个发电站+15%"——同上，**不被冬时归零**
- 冬时自身+30%（3人×10%）加上队友的设施加成
- 所以冬时+清流+温蒂在342（3贸易2发电）= 冬时30% + 清流60% + 温蒂30% = **120%**（注意这里温蒂只吃到2发电不是4发电，因为森蚺+Lancet体系在另一队A班）

## 七、等效效率概念

**纸面效率** vs **等效效率**是两个不同概念：

| 概念 | 含义 | 举例 |
|------|------|------|
| **纸面效率** | 技能描述中直接写的百分比 | 订单获取效率+30% |
| **等效效率** | 特殊机制折算成百分比后的总收益 | 但书等效+165%、图耶+但书等效+260% |

**特殊机制的等效折算方法：**

| 机制 | 等效逻辑 |
|------|---------|
| **但书违约** | 非4赤金订单变违约→多交付2赤金→同等时间内处理更多赤金=无形中缩短订单周期 |
| **龙舌兰+500** | 大单额外+500龙门币=等效增加收益，折算为效率% |
| **鸿雪生产线** | 加速赤金消耗=缩短订单周期=等效提高订单效率 |
| **可露希尔特别订单** | 固定获取特殊订单，价值独立于普通订单 |
| **雪雉放大器** | 队友每5%额外5%，本身不增加纸面但增加等效 |

## 八、设计时的查询策略

### 正确流程

**第一步：穷举可用干员清单**

不要先想"我打算用巫恋+龙舌兰"，而是：

```bash
# 列出所有你拥有的、在某设施有技能的干员
cd /d/workspace/PRTS
grep -E "TRUE" 干员练度表.txt | awk -F'\t' '{print $1}' > /tmp/owned.txt
# 贸易站
grep -f /tmp/owned.txt skills_parsed.txt | grep "|贸易站|" | sort
# 制造站
grep -f /tmp/owned.txt skills_parsed.txt | grep "|制造站|" | sort
# 发电站
grep -f /tmp/owned.txt skills_parsed.txt | grep "|发电站|" | sort
# 控制中枢
grep -f /tmp/owned.txt skills_parsed.txt | grep "|控制中枢|" | sort
```

读这个清单，**不跳过任何一个名字**，特别是4星5星。

**第二步：识别组合链**

穷举后，逐组匹配：
1. 赤金生产线链路：鸿雪→图耶→绮良→杜林族→可露希尔
2. 深海猎人链路：歌蕾蒂娅(中枢)→斯卡蒂/幽灵鲨/乌尔比安/安哲拉(制造)
3. 莱茵生命链路：娜斯提→多萝西→缪尔赛思→其他莱茵
4. 格拉斯哥帮链路：摩根→推进之王→戴菲恩(中枢)
5. 红松骑士团链路：野鬃→灰毫→正义骑士号(发电)
6. 苍苔金属工艺链路：苍苔→引星棘刺→其他金属工艺干员
7. 叙拉古链路：贝洛内→伺夜→八幡海铃(中枢)
8. 精英干员链路：真言→各精英干员分布设施

**第三步：计算等效效率**

对每个组合，同时计算纸面效率和等效效率，标注特殊机制。

**第四步：跨班次分配**

- 12小时核心班：上高等效效率组合（如龙舌兰组+鸿雪赤金生产线）
- 6小时替补班：上第二梯队但仍有链路的组合
- 6小时夜班：上深海猎人/红松骑士团/独立高效组合
