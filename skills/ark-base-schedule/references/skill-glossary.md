# 机制与字段词典

| 字段或标签 | 含义 |
|---|---|
| `direct_bonus_pct` | 当前房间直接效率或生产力加成 |
| `facility_bonus_pct` | 按贸易站、发电站等设施数量计算的加成 |
| `global_bonus_pct` | 按全局或同房间群组计数计算的加成 |
| `multiplier` | 对百分比结果执行的乘算 |
| `fixed_order_value_lmd_per_trigger` | 每次触发的独立龙门币价值 |
| `override_room_direct_bonus` | 替换当前房间直接加成层 |
| `dongshi_reset` | 将制造站直接生产力替换为站内人数乘固定值 |
| `production_lines` | 鸿雪体系中的赤金生产线计数 |
| `global_operators` | 全局计数使用的干员范围 |
| `strict_rotation` | 同一干员一天只分配一次 |
| `allowed_with_warning` | 跨班复用保留为警告 |
