# 机制与字段词典

| 字段或标签 | 含义 |
|---|---|
| `direct_bonus_pct` | 当前房间直接效率或生产力加成 |
| `facility_bonus_pct` | 按贸易站、发电站等设施数量计算的加成 |
| `global_bonus_pct` | 按全局或同房间群组计数计算的加成 |
| `multiplier` | 对百分比结果执行的乘算 |
| `fixed_order_value_lmd_per_trigger` | 每次触发的独立龙门币价值 |
| `override_room_direct_bonus` | 替换当前房间直接加成层 |
| `dongshi_reset` | 将制造站直接生产力替换为站内人数乘固定值 |
| `production_lines` | 鸿雪体系中的赤金生产线计数 |
| `global_operators` | 全局计数使用的干员范围 |
| `strict_rotation` | 同一干员一天只分配一次 |
| `allowed_with_warning` | 跨班复用保留为警告 |
| `product_options` | 房间在不同操作区间允许选择的产品集合 |
| `intermediate_products` | 当班实时汇总的人间烟火、巫术结晶、感知信息、思维链环、无声共鸣、魔物料理和工程机器人 |
| `positive_order_capacity_increase` | 只累计正向订单上限，供琳琅诗怀雅、锏等转效率技能读取 |
| `tag_registry.py` | 结构化 tag 的唯一消费者注册表与发布门禁 |
| `inventory_timeline` | 上线节点与区间末收取事件构成的日内库存轨迹 |

## 控制中枢心情结算顺序

1. 从干员基础消耗 `1.0/小时` 开始。
2. 应用该干员自身的增减耗；令“杯莫停”先消除当前中枢岁干员的自身心情消耗影响。
3. 应用同房间全体恢复、同组恢复和指定对象恢复。
4. 应用中枢进驻人数提供的其他设施恢复，以及玛恩纳、重岳、巴别塔等特殊比较规则；标记特殊比较的同层效果取最高。
5. 应用生产房间满员减耗和宿舍实际恢复，将结果截到不低于 `0`。

心情阈值在每个班次开始读取当前心情；班次结束后扣除工作消耗或增加实际宿舍恢复。令、夕跨越 `12` 后，下一个班次重新选择人间烟火或感知信息来源。
