# 模型范围

## 已实现

- 基于 roster 和精英等级的技能资格筛选。
- 单房间候选组合枚举。
- 质量候选与多样性候选保留。
- 跨房间、跨区间二元 MILP。
- 同时进驻排他约束。
- 逐班心情消耗、宿舍恢复和重复日闭环。
- 源石碎片生产和订单消耗约束。
- 工厂仓库封顶代理。
- 同组合连续工作奖励。
- 多候选无好割搜索。
- 同时基建范围效率复算。
- 仓库溢出、碎片平衡和保守心情报告。
- SciPy HiGHS 的 gap、双界和节点信息。

## 部分实现

- 控制中枢和全局联动：在求解后复算，尚未完整进入 MILP。
- 特殊订单：保留机制和固定价值字段，未统一换算随机日产。
- 心情：支持工时与保守恢复率，尚未自动分配宿舍床位和氛围。
- 外部证据：可加入候选池，只有结构化数值会参与评分。

## 尚未实现

- 无人机作为逐时决策变量。
- 随机龙门币订单分布和库存队列。
- 菲亚梅塔、宿舍床位、宿舍氛围的联合优化。
- 所有当前干员的完整技能数据。
- 所有非线性特殊技能的精确线性化。
- 最终复算目标的数学全局最优证明。
