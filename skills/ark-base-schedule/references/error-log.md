# 排班设计错误日志（持续更新）

每次发现排班设计中的错误后记录，避免下次再犯。**设计排班前必读本文件。**

## 错误 #1: 默认技能全部已解锁

**表现:** 假设龙舌兰E0有E2技能(+500)、巫恋E1有精2技能(低语)、雪雉E0有E2技能(天道酬勤β)
**后果:** 效率估算虚高，方案不可执行
**正确做法:** 每次设计前查干员练度表确认精英等级，只在精英达标的情况下计算技能效果。

## 错误 #2: 清流的技能机制认知错误

**表现:** 以为清流是"25%标准化"，实际技能是"每个贸易站为贵金属类配方+20%"
**正确数值:** 清流E1技能——每个贸易站→赤金+20%。

## 错误 #3: 但书和龙舌兰并非纯效率加成

**表现:** 但书没有直接效率加成(0%)，而是通过违约机制(2→4赤金、3→5)等效增伤
**正确认知:** 但书和龙舌兰的收益不能用固定百分比衡量，要用"等效效率"概念。

## 错误 #4: 源石类/赤金类/作战记录类的技能有配方限制

**表现:** 源石类配方技能不会加成到赤金制造，配错产品就浪费了
**正确做法:** 检查每个制造干员的技能说明中的配方限制词。

## 错误 #5: 对无技能/未解锁干员使用默认值

**表现:** 芬E0、霜叶E0等在计算器中显示0%制造效率
**影响:** 制造站技能是精1才解锁的(E0无技能)，需要确认搭配

## 错误 #6: 同一个人在不同班次中重复使用

**表现:** A班用了但书B班又用，但书被连续调度16小时，心情不够
**正确做法:** 三班制下同一干员只能在不相邻的两个班次出现（间隔≥12小时）

## 错误 #7: 查询技能不够彻底，漏了大量关键干员

**表现:** 设计时只查了有限的干员，跳过了大量有制造/贸易技能的4/5星干员
**具体漏掉的：** 绮良、图耶、鸿雪、冬时、引星棘刺、苍苔、阿罗玛、多萝西、娜斯提、野鬃、灰毫、火神、泡泡、斥罪、摩根、戴菲恩等
**正确做法:** 用 grep 导出所有干员技能清单，逐行过一遍，不跳过任何名字。

## 错误 #8: 不了解等效效率概念

**表现:** 只算了直接百分比的加法（砾35%+斑点30%+夜烟30%=95%），没有把特殊机制折算成等效百分比
**后果:** 低估了但书(等效+165%)、龙舌兰(+500)、鸿雪生产线(等效110%)等组合的真实效率
**正确做法:** 对每个特殊机制单独计算等效效率，同时输出纸面效率和等效效率。

## 错误 #9: 忽略跨房间全局计数器

**表现:** 没有追踪"基建内有几个杜林族"、"几个莱茵生命"、"几个精英干员"这种全基建条件
**后果:** 无法发现鸿雪+4杜林赤金生产线、娜斯提+莱茵生命等依赖全局计数的组合
**正确做法:** 设计时列表追踪所有全局计数器。

## 错误 #10: 不知道菲亚梅塔充电体系

**表现:** 完全不知道菲亚梅塔可以给但书/清流等高消耗干员回复心情
**后果:** 对高心情消耗干员的连续工作能力估计不足
**正确做法:** 菲亚梅塔进驻宿舍时，可以给指定干员提供额外心情回复。

## 错误 #11: 设计流程顺序错误

**表现:** 先想好"我打算用什么组合"→再查技能验证→发现不对
**正确顺序:** 先穷举所有可用干员→发现组合链和全局计数器→再设计方案→最后用计算器验证
