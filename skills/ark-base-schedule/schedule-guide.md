## 核心认知（设计排班前必须理解）

### 1. 排班是全局系统设计，不是单房间优化

错误做法：先想"贸易站1放谁+谁+谁=多少%"→再想"制造站1放谁+谁+谁=多少%"

正确做法：先想链路→再分配房间

```
链路思维：
  "我要有4个杜林族 → 激活鸿雪生产线 → 绮良翻倍 → 图耶加成 → 但书×1.556乘算"
  → 然后才决定：哪些干员进贸易站、哪些进制造站、哪些放中枢
```

### 2. 等效效率才是评价指标

| 概念 | 含义 | 举例 |
|------|------|------|
| **纸面效率** | 技能描述的简单加法 | 月见夜+30% |
| **等效效率** | 纸面+乘算+全局+独立收益的总和 | 但书纸面0%但等效≈+54%~260% |

纸面效率是误导的。决策必须基于等效效率。

### 3. 五层叠加体系

效率计算分为五个独立层级，必须按正确顺序叠加：

```
第1层：干员纸面（互相叠加/巫恋低语清空替代）
第2层：设施数量加成（每个贸易站/发电站/宿舍加X%）
第3层：全局计数器（杜林/莱茵/精英干员数量→转化）
第4层：乘算区（但书×1.556等）
第5层：独立收益（龙舌兰大单+500等）
```

### 4. 三班不是简单的A休B上

正确答案中A班和B班的贸易站是完全一样的——核心组合被菲亚梅塔充电支撑，可以连续18小时运转。真正换的是制造站。

```
A班12小时：核心链路贸易 + 高倍率制造
B班6小时：核心链路贸易 + 第二梯队制造
C班6小时：完全独立的另一套链路（叙拉古/格拉斯哥帮/深海猎人）
```

## 七条核心链路（设计时逐条检查）

每条链路的核心干员和全局计数器条件：

### ① 赤金生产线（最高效贸易链路）
```
条件：4个杜林族进驻设施（桃金娘/杜林/褐果）
干员：鸿雪E2（每生产线+5%）+ 图耶E2（每2条+15%）+ 绮良E2（翻倍）
      可露希尔（特别订单）/ 但书E2（×1.556乘算）
计算：实际4条 + 杜林4条 = 8条 → 绮良翻倍 = 8或12条
      鸿雪+40%~60% | 图耶+60%~95% | 但书×(1.556)
```

### ② 深海猎人（制造站链路）
```
条件：歌蕾蒂娅进驻中枢
干员：斯卡蒂 + 幽灵鲨 + 乌尔比安 + 安哲拉（制造站）
效果：歌蕾蒂娅中枢提供深海猎人特殊加成
```

### ③ 莱茵生命（制造站链路）
```
条件：其他莱茵干员分布全基建
干员：娜斯提（每莱茵+3%赤金，最多5名）+ 多萝西（莱茵科技联动）
      缪尔赛思（电站，每莱茵+3%无人机）
```

### ④ 格拉斯哥帮（贸易站链路）
```
条件：全基建格拉斯哥帮干员数量
干员：摩根（每同站格拉斯哥+20%）+ 推进之王
      戴菲恩（中枢，每格拉斯哥+10%）
```

### ⑤ 叙拉古（贸易站链路）
```
条件：全基建叙拉古干员数量
干员：贝洛内 + 伺夜 + 八幡海铃（中枢，每叙拉古+5%）
```

### ⑥ 金属工艺（制造站链路）
```
条件：同站有金属工艺标签干员
干员：苍苔（每金属工艺+5%）+ 引星棘刺（每贸易站+3%）
      砾/斑点/夜烟/温米（金属工艺基础+30%）
```

### ⑦ 红松骑士团（制造站链路）
```
干员：野鬃 + 灰毫 + 正义骑士号（发电站联动）
```

## 设计流程

### Step 1: 穷举可用干员清单

```bash
grep -E "TRUE" 干员练度表.txt | awk -F'\t' '{print $1}' > /tmp/owned.txt

echo "=== 贸易站 ===" && grep -f /tmp/owned.txt skills_parsed.txt | grep "|贸易站|" | sort
echo "=== 制造站 ===" && grep -f /tmp/owned.txt skills_parsed.txt | grep "|制造站|" | sort
echo "=== 发电站 ===" && grep -f /tmp/owned.txt skills_parsed.txt | grep "|发电站|" | sort
echo "=== 控制中枢 ===" && grep -f /tmp/owned.txt skills_parsed.txt | grep "|控制中枢|" | sort
```

**关键：** 逐行读完，不跳过任何名字，特别是4/5星干员。

### Step 2: 识别可用的链路

逐条检查七条核心链路：
1. 有鸿雪+图耶+绮良？有4个杜林族？→ **赤金生产线链路可用**
2. 有歌蕾蒂娅+斯卡蒂+幽灵鲨？→ **深海猎人链路可用**
3. 有娜斯提+多萝西+其他莱茵？→ **莱茵生命链路可用**
4. 有摩根+推进之王+戴菲恩？→ **格拉斯哥帮链路可用**
5. 有贝洛内+伺夜+八幡海铃？→ **叙拉古链路可用**
6. 有苍苔+引星棘刺+砾/斑点/夜烟？→ **金属工艺链路可用**
7. 有野鬃+灰毫？→ **红松骑士团链路可用**

同时确认全局计数器初始值：
- 杜林族____个 → 影响鸿雪生产线
- 莱茵生命____个 → 影响娜斯提/缪尔赛思
- 精英干员____个 → 影响真言
- 深海猎人____个 → 影响歌蕾蒂娅加成
- 格拉斯哥帮____个 → 影响摩根/戴菲恩
- 叙拉古____个 → 影响八幡海铃

### Step 3: 计算等效效率

```bash
python scripts/efficiency_calculator.py 贸易站 "巫恋,龙舌兰,绮良"
python scripts/efficiency_calculator.py 制造站 "清流,温蒂,冬时" "贵金属"
python scripts/efficiency_calculator.py --check {方案文件.json}
```

效率计算器的五层输出结构：
```
干员纸面: +XX%   ← 干员技能的直接加法
设施加成: +XX%   ← 按贸易站/发电站/宿舍数量计算
全局计数: +XX%   ← 跨房间统计（杜林/莱茵/精英等）
纸面合计: +XX%   ← 以上三层相加
乘算区: ×1.556  ← 但书等独立乘区
等效效率: XX%    ← 纸面合计×乘算区=真实的等效效率
```

### Step 4: 设计三班分配

**A班12小时（核心链路）：**
- 贸易3站上**赤金生产线链路**（鸿雪+图耶+绮良+但书等）
- 制造用**莱茵+金属工艺+自动化**等高倍率组合
- 中枢上森蚺（+Lancet-2→发电站+2）

**B班6小时（复用贸易核心）：**
- 贸易3站和A班**完全一样**（菲亚梅塔充电支撑核心干员）
- 制造换**红松骑士团/泡泡+火神**等第二梯队

**C班6小时（独立链路）：**
- 贸易上**叙拉古/格拉斯哥帮**等另一套链路
- 制造上**深海猎人/金属工艺**等
- 中枢换歌蕾蒂娅（激活深海猎人）

**菲亚梅塔充电：**
- 但书、清流、可露希尔等高消耗干员需要充电才能连续18小时
- 菲亚梅塔进驻宿舍 → 给指定干员额外心情回复

### Step 5: 验证

```bash
python scripts/efficiency_calculator.py --check {排班文件.json}
```

检查：
- 等效效率是否合理（但书组应显著高于纸面）
- 全局计数器是否正确（杜林/莱茵/叙拉古数量）
- 同班次是否有重复干员
- 相邻班次是否有冲突
- 制造站产品类型是否匹配（不要限作战记录放赤金站）

对照 [schedule-checklist.md](schedule-checklist.md) 逐项检查。

## 常见误区

- ❌ 只看纸面效率做决策 → ✅ 用等效效率
- ❌ 先想"放谁"再想"有多少条链路" → ✅ 先识别可用链路再分配
- ❌ 三班各放不同人 → ✅ 核心贸易组可复用（需菲亚梅塔充电）
- ❌ 认为但书和龙舌兰是加法 → ✅ 但书是×1.556乘算，龙舌兰是独立收益
- ❌ 忽略杜林族/莱茵等全局计数器 → ✅ 这些决定链路能否激活

## 无人机加速优先策略

- 优先加速贸易站（钱比赤金更容易成为瓶颈）
- 参考优先级：1/2级站但书 > 3级站龙舌兰 > 但书同时吃 > 3级站巫恋 > 龙舌兰
