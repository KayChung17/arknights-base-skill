# 快速开始

## 1. 准备干员表

支持 TSV、CSV 和 XLSX。推荐字段：

```text
干员名称 | 是否已招募 | 等级 | 精英化等级 | 当前心情
```

未招募干员会被忽略。当前心情可以留空，留空时模型会使用配置中的保守假设。

## 2. 复制项目配置

```bash
cp examples/configs/合成玉优先_布局搜索.json project.json
```

至少修改：

- `roster`
- `objective.online_times`
- `objective.minimum_net_lmd_per_day`
- `base_state.drone_capacity`
- `base_state.initial_drone_stock`
- 宿舍与右侧设施等级

## 3. 检查环境

```bash
python arkbase.py doctor
```

## 4. 运行

```bash
python arkbase.py run project.json \
  --output-dir output/my-project
```

## 5. 阅读结果

先看 `audit.json`：

- `passed`：硬约束和内部一致性检查通过。
- `passed_with_warnings`：结果可读，但存在缺失计划、未建模信息或复现提示。
- `failed`：至少一个硬约束或最优性声明不成立。

再看 `report.md` 和 `result.json`。排班执行前仍应核对自己的当前库存、心情和建筑等级。
